### How the rules batch was built — repeat this shape for signs

The method that worked, and why:

1. **Derive every question from a learning object that already carries a citation.** Do not write
   free-hand. `objective_code` and `source_citation` are then *inherited*, so a wrong answer is
   traceable to a provision instead of to nobody.
2. **Compute quotas first** — bring every objective to a floor, then top up the thinnest. Gives
   agents an exact `write` count per objective and stops them over-covering the easy ones.
3. **One shared brief file** (`scratchpad/BRIEF.md`) + one small batch file per agent. Keeps
   prompts short and the house style identical across agents.
4. **Validate before seeding**: option count, answer index in range, no duplicate options, no
   duplicate prompt against the existing bank *or* within the new set, explanation non-empty.
   All 79 passed; the check is worth keeping.
5. **Seed via a committed idempotent script**, never ad-hoc REST.

## Gotchas that cost time today — don't rediscover them

- **`road_signs` primary key is `sign_id`, not `code`.** PostgREST upserts need
  `?on_conflict=code` or they 409 on `road_signs_code_key`.
- **`UID` is a readonly bash variable.** Use another name in shell scripts.
- **The SARTSM PDF is two-column** — `pdftotext` interleaves the columns and splits clauses
  mid-sentence. Never reconstruct a legal duty from the text dump; read the PDF pages.
- **`grok-review` blows the argv limit** on a large diff. Write the diff to a file and use
  `--file`.
- **Gemini's MCP backend is broken** (`agy` binary missing), so `--max` reviews effectively run
  Grok + Codex only.
- **Adversarial reviewers produce confident false positives.** Grok returned five wrong HIGHs
  today — claiming migration columns and a unique index were missing when both were present and
  verified. Always adjudicate against the codebase before acting.
- **Node's test runner needs explicit `.ts` import specifiers**, which requires
  `allowImportingTsExtensions` in tsconfig. Safe because typecheck is `--noEmit` and Next uses SWC.
