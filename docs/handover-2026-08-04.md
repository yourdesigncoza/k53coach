## Traps recorded today — read before citing or measuring

**The 2014 amendments sit beyond our consolidated copy.** `resources/legislation/` has the NRTR
consolidated to **GNR.209 of 9 Mar 2012**, but **GNR.846 of 31 Oct 2014** substituted reg 149
wholesale and amended reg 213. Today's first citation pass quoted superseded reg 149 wording.
**Check `nrtr-amendment-2014-gg38142-gnr846.pdf` as well as the consolidation, every time.**

**A verification model fabricated a regulation number.** In the adversarial review, one model
raised its only HIGH claiming NRTR reg 304 governs unattended vehicles and reg 305 the stopping
prohibitions. The text says the opposite — **304 *is* "Stopping of vehicles"** and 304(h) is
verbatim our cited rule. It cited from recall. Never take a model's regulation number without
opening the text — and note this is the strongest available argument for item (a) above.

**Two of four tests I wrote today passed vacuously.** The option-shuffle tests asserted
`options[answer] === CORRECT`, which holds without any shuffling because the fixture puts the
correct text at the stored index. Three independent reviewers caught it. **The check that settles
it is to revert the fix and confirm the test fails** — assertion-by-inspection is not enough.

**`pkill` returns 144 and aborts a `&&` chain**, silently skipping everything after it. Bit me

## Open, non-blocking

- **`VC20` is a control lesson with no question.** Pre-existing. The Stage 1 orphan gate measures
  the other direction (questions with no lesson, clean at 274/274).
- **`readinessQuota` over-allocates below size 3** — returns `{1,1,1}` for size 1 or 2, then
  slices, so small samples are biased toward the first topics. Unreachable in production (size is
  always 5) and untested below 3. Only matters if the sample size becomes configurable.
- **`q-controls-5`, `VC-016` and the other five uncitable questions** are approved with
  `source_basis = 'uncited_general_knowledge'` and `source_citation` NULL, deliberately. **Do not
  backfill that column** — `source_citation is null` is the query that returns exactly this set.
- **`attempts.chosen_index` is ambiguous, and now more so.** It indexes the *displayed* option
  order, which is shuffled per sitting, so the same canonical choice stores as different numbers
  across attempts. **Pre-existing** — the mock exam has always shuffled — but practice now shares
  it. Currently harmless: the column is **write-only**, never read, and `correct` is stored
  alongside, so pass/fail is unambiguous. What it forecloses is distractor analysis ("which wrong
  answer do learners pick?"), which would need the displayed order or a canonical option id
  persisted. Schema change, and it should cover exams too.
- **One malformed row can 500 a whole practice topic.** `shuffleOptions` throws on an out-of-range
  answer index and `getShuffledPracticeQuestions` maps every row, so one bad row takes the page
  down rather than rendering one bad question. Introduced 2026-08-04. Risk is low —
  `saveQuestion` guards writes and all 274 rows are valid — but `scripts/data-repairs/*` bypass
  that guard, which is why the throw exists. Isolating per-row would restore silent-bad-question
  behaviour, so it is a real trade, not an obvious fix.
- **Two hard numbers live in the copy** and go stale the day the figure moves:
  `landing.cred2Title` ("356 signs & markings") and `paywall.incl1` ("growing to 750+").
